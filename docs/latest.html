🔥 Today's Top Takeaway

The Capability Funnel: Extreme Concentration at the Frontier

Karpathy's funnel framing dominated the day: ~6B barely touched LLMs, ~20M professionals see agentic coding first-hand, and only ~5,000 have internal frontier access. Simultaneously, context windows and inference silicon race ahead — capability is compounding for a tiny sliver while most of the world sees a derpy chatbot.
Key Points:

1. A four-tier capability funnel: 6B untouched / 1-2B casual / 20M professional math&code / 5,000 internal. Driven by ambition of the problem, jaggedness of capability, and access.
2. Context becomes infrastructure: GPT-6.1 Sol default context in Codex & Work jumps to 500k (max 1M) with no long-context fees — fewer compactions, more nuance retained.
3. Deterministic over LLM where possible: Garry Tan argues replacing LLM calls with deterministic code yields better code that matches user intent — a maturing engineering discipline.
4. Legibility as a design constraint: Thariq echoes Terence Tao: an opaque superintelligence is not a goal; communication and shared understanding are signals of real intelligence.
Implications:

1. Alpha sits inside the top of the funnel: Only ~5,000 people operate frontier systems daily. Their workflows are the most valuable, least distributed knowledge in tech right now.
2. Two different products, two different markets: Serving 1-2B casual users is a consumer UX problem; serving 20M professional coders is an agent-infrastructure problem. Don't conflate them.
3. Speed and context are the new moats: Fractile bets a 3-6 month structural speed lead wins every deployment; OpenAI pushes 500k-1M context as default. Inference economics are the battleground.
Bottom line: The curve isn't bending for everyone at once — it's a funnel. Value accrues to those who build at the frontier while translating that capability downward to everyone else.

能力漏斗：前沿能力极端集中

Karpathy 的“能力漏斗”成为今日主线：约 60 亿人几乎未接触 LLM，约 2000 万专业人士亲历智能体写码，仅约 5000 人可用内部前沿系统。同时上下文窗口与推理芯片高速演进——极少数人的能力在指数级复利，而多数人只看到笨拙的聊天机器人。
关键要点：

1. 四级能力漏斗: 60 亿未接触 / 10-20 亿轻度使用 / 2000 万数学与代码专业人士 / 5000 内部用户。由问题野心、能力锯齿度与访问权限共同驱动。
2. 上下文成为基础设施: GPT-6.1 Sol 在 Codex 与 Work 默认上下文升至 500k（上限 1M）且不收长上下文费，减少压缩、保留更多细节。
3. 能用确定性代码就别调 LLM: Garry Tan 认为以确定性代码替代 LLM 调用能产出更契合用户意图的代码，标志工程实践趋于成熟。
4. 可解释性是设计要求: Thariq 呼应陶哲轩：不透明的超级智能不应被接受，沟通与共识才是真正智能的信号。
启示：

1. Alpha 藏在漏斗顶端: 仅约 5000 人日常使用前沿系统，其工作流是当下最有价值、传播最少的知识。
2. 两种产品，两个市场: 服务 10-20 亿轻度用户是消费级体验问题；服务 2000 万专业程序员是智能体基础设施问题，不可混为一谈。
3. 速度与上下文是新护城河: Fractile 押注 3-6 个月结构性速度领先即可赢下全部部署；OpenAI 把 500k-1M 上下文设为默认。推理经济学成为主战场。
总结：曲线不会同时惠及所有人，它是个漏斗。价值属于那些在前沿构建、同时把能力向下传递给多数人的团队。
