🔥 Today's Top Takeaway

Serving the Agentic Economy: Capacity, Connectivity, Deployment

Demand is outrunning supply while the plumbing for agents gets built out. OpenAI is racing to double inference speed for GPT-6.1 Sol and now lets anyone build and deploy MCP servers inside ChatGPT. Meanwhile Vercel's Connect targets the credential mess of connecting apps and agents, and Box's Levie argues the real money is in the far harder work of deploying AI as work output inside enterprises.
Key Points:

1. Inference capacity is the new bottleneck: GPT-6.1 Sol is the most demanded model ever across API and subscriptions; OpenAI is adding capacity to nearly double speed.
2. MCP goes mainstream and self-serve: Building, deploying and scoping MCP servers now happens directly inside ChatGPT — distribution for the connector layer.
3. Connectivity beats code: With code cheap, Vercel argues connecting services is the final boss, and static credentials are the main liability.
4. AI deployment is not software deployment: Levie: legacy migration, data access, workflow reengineering, HITL, evals and constant model upgrades create a new services layer.
5. Human-centered demand persists: Altman: expectations and latent demand keep rising; humans remain at the center even as low-creativity tasks shift to AI.
Implications:

1. For builders: Ship agent-native connectivity and permissions early; MCP inside ChatGPT is now a distribution channel.
2. For enterprises: Budget for the unglamorous work: data access, workflow redesign, HITL and eval maintenance.
3. For investors: Watch the FDE/services layer and agent infra — and the pressure Anthropic's ARR plateau puts on SaaS multiples.
Bottom line: The model race is now a capacity race, and the durable value is shifting to whoever connects and deploys agents into real workflows.

服务智能体经济：算力、连接与部署

需求正跑赢供给，而智能体的基础设施正在被快速搭建。OpenAI 争分夺秒将 GPT-6.1 Sol 推理速度翻倍，并允许任何人在 ChatGPT 内构建部署 MCP 服务器。Vercel 的 Connect 直指应用与智能体连接的凭证乱局；Box 的 Levie 则主张，真正的钱在企业内部把 AI 作为工作产出部署这一艰难得多的工作上。
关键要点：

1. 算力成为新瓶颈: GPT-6.1 Sol 是 API 与订阅端史上最热门模型；OpenAI 正扩充算力使速度近乎翻倍。
2. MCP 走向主流与自助化: MCP 服务器的构建、部署与权限控制已可直接在 ChatGPT 内完成——连接层的分发入口。
3. 连接比代码更重要: 代码变便宜后，Vercel 认为连接服务才是终极难题，静态凭证是最大隐患。
4. AI 部署≠软件部署: Levie：遗留系统迁移、数据接入、流程重构、HITL、评测与持续模型升级催生新服务层。
5. 以人为本的需求持续存在: Altman：期待与潜在需求不断上升；即便低创造性任务交给 AI，人依然是核心。
启示：

1. 对开发者: 尽早做出智能体原生的连接与权限方案；ChatGPT 内的 MCP 已是分发渠道。
2. 对企业: 为不性感的工作留预算：数据接入、流程重构、HITL 与评测维护。
3. 对投资人: 关注 FDE／服务层与智能体基础设施，以及 Anthropic ARR 趋平对 SaaS 估值的压力。
总结：模型竞赛已变为算力竞赛，而持久价值正转向那些把智能体连接并部署进真实工作流的人。
