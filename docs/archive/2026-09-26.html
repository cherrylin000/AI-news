🔥 Today's Top Takeaway

Multi-Model Reality Arrives; Value Migrates to the Layer Between GPUs and Models

Today's feed shows a market re-sorting in real time. Gateway spend data from Vercel reveals Anthropic's share halving (69%→40%) while OpenAI doubles and open-weight models (Kimi K3, DeepSeek) absorb the rest — proof that model choice is now liquid. At the same time agents are being productized fast (Replit Muse, Claude Code modes, 43 Claude SMB workflows), and VAST Data's CEO describes AI-cloud storage demand jumping from 500PB plans to 2.5+ exabytes in one cycle. Competition is shifting from who has the best model to who owns the routing, tooling, and data layer underneath.
Key Points:

1. Anthropic's Spend Share Halved: On Vercel's AI Gateway, Anthropic fell from 69% to 40% of spend in two months while OpenAI rose 10%→24% and now leads in tokens; open-weight models took roughly half of Anthropic's loss. Opus 5.5 already reached 10% of spend within two days, showing share is volatile and launch-driven.
2. Agents Are Being Productized, Not Demoed: Replit's Muse now builds apps, Claude Code is turning plan mode into a composable mod with custom modes, and Claude SMB ships 43 workflows and 27 integrations with 900K+ installs. Agent capability is moving from novelty to packaged, repeatable workflow.
3. Infrastructure Demand Outruns Every Forecast: VAST Data's CEO recounts an AI cloud planning 500PB over three years, then returning a week later needing two extra exabytes. He frames the software infrastructure layer as 'the operating system for this new era' — the layer models and hardware both depend on.
Implications:

1. Route, Don't Marry: With share shifting this fast, teams should abstract model access behind a gateway and treat model choice as a routing decision driven by cost, latency, and capability — not a long-term commitment.
2. The Middle Layer Is the Opportunity: Storage, data orchestration, and agent tooling are where demand is outrunning supply and forecasts. For builders, this layer offers more defensibility than yet another application wrapper.
3. Prompt for Ambition, Not Chores: Steinberger's heuristic — give agents a quantified, aggressive goal instead of 'clean up' — is a concrete reminder that agent output quality is largely a specification problem.
Bottom line: Model leadership is now a moving target, so the durable advantage belongs to those who own the routing, workflow, and data infrastructure underneath — design for a multi-model world and build where demand already exceeds forecasts.

多模型格局成型，价值正向 GPU 与模型之间的中间层迁移

今日信息显示市场正在实时重排：Vercel AI Gateway 数据显示 Anthropic 份额从 69% 腰斩至 40%，OpenAI 翻倍，Kimi K3 与 DeepSeek 等开放权重模型吃下剩余空间——模型选择已彻底流动化。同时智能体被快速产品化（Replit Muse、Claude Code 模式化、Claude 中小企业版 43 个工作流），VAST Data CEO 则透露 AI 云存储需求在一个周期内从 500PB 计划跳升至 2.5EB 以上。竞争正从“谁模型最强”转向“谁掌握底层路由、工具与数据层”。
关键要点：

1. Anthropic 支出份额腰斩: Vercel AI Gateway 上，Anthropic 两个月内从 69% 降至 40%，OpenAI 从 10% 升至 24% 并在 token 量上登顶；开放权重模型吃下 Anthropic 流失份额的约一半。Opus 5.5 上线两天即占 10%，说明份额高度波动且由新品发布驱动。
2. 智能体从演示走向产品化: Replit 的 Muse 可直接建应用，Claude Code 把 plan mode 做成可组合的 mod 并支持自定义模式，Claude 中小企业版一次交付 43 个工作流、27 个集成、安装量超 90 万。代理能力正在变成可打包、可复用的工作流。
3. 基础设施需求持续超出预测: VAST Data CEO 提到某 AI 云原本规划三年 500PB，一周后追加 2EB。他把软件基础设施层称为“新时代的操作系统”，是模型与硬件双向依赖的中间层。
启示：

1. 做路由，别做绑定: 份额变动如此之快，团队应把模型访问抽象到网关之后，把选型当作由成本、延迟、能力驱动的路由决策，而非长期承诺。
2. 中间层才是机会: 存储、数据编排与智能体工具是需求远超供给与预测的环节。对开发者而言，这一层的护城河比再做一个应用壳更深。
3. 用雄心而非杂活写提示词: Steinberger 的经验——给智能体一个可量化的激进目标，而不是“清理一下”——说明产出质量本质上是规格定义问题。
总结：模型领先地位已成流动目标，真正的持久优势属于掌握底层路由、工作流与数据基础设施的一方：为多模型世界而设计，在需求已跑赢预测的地方下注。
