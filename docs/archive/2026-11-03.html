🔥 Today's Top Takeaway

Hours, Not Months: Agentic Builders vs. an Inefficient Compute Market

Today's signal is asymmetric: on the product side, single builders now few-shot entire apps in hours, with agents doing setup, hardening and deployment. On the infrastructure side, compute remains opaque and negotiated deal-by-deal, with subsidies masking real costs and open-source/local stacks positioned as the hedge.
Key Points:

1. Manual work collapses to 3 steps: Karpathy's only hands-on actions were an API key, a VPS and a domain—everything else was agent-executed.
2. Data as the moat: The value came from filtering 43M comments into 6,454 curated videos, not from UI code.
3. Compute is not fungible: Modal's CEO describes GPU sourcing as lobby deals across 25 clouds; capacity exists but at higher prices and longer terms.
4. Subsidy risk is priced in: Builders openly warn that cheap AI subscriptions will be repriced as unit economics bite.
Implications:

1. Redesign for agent-first: Assume an agent owns deploy, hardening and optimization; your interface is prompts plus credentials, not dashboards.
2. Buy optionality, not a single vendor: Own harness, data and runtime so model, cloud or subscription repricing doesn't strand your product.
3. Vertical data curation is the product: Curation over raw aggregation is where defensibility sits—replicable in hours, but only with the right corpus.
Bottom line: The cost of building just dropped to hours; the cost of running it is still negotiated behind closed doors. Builders who own their stack and their data will capture the gap.

小时级交付的 Agent 建造者，对上尚未成熟的算力市场

今日信号呈非对称：产品侧，单个开发者已能在数小时内把完整应用“few-shot”出来，由 agent 完成部署、加固与优化；基础设施侧，算力依旧不透明、逐笔谈判，补贴掩盖真实成本，开源与本地栈被当作对冲手段。
关键要点：

1. 人工只剩三步: Karpathy 亲手做的只有 API key、VPS 和域名，其余全部由 agent 执行。
2. 护城河是数据: 真正价值在于把 4300 万条评论筛成 6454 个精选视频，而非前端代码。
3. 算力不可互换: Modal CEO 称拿卡靠酒店大堂谈单、横跨 25 家云；产能有，但价格更高、周期更长。
4. 补贴风险已被计入: 多位创始人公开预警：便宜的 AI 订阅将随单位经济性回归而被重新定价。
启示：

1. 按 Agent 优先重构: 默认 agent 接管部署、加固与优化；你的接口是 prompt 加凭据，而不是控制台。
2. 买选择权而非绑定单一供应商: 掌控 harness、数据与 runtime，模型、云或订阅涨价时才不会让产品被卡死。
3. 垂直数据策展即产品: 壁垒在策展而非抓取——只要有对的语料，几小时即可复制。
总结：构建成本已降到小时级，运行成本仍在闭门谈判中定价。掌控自有栈与数据的建造者，将吃掉这段差价。
